PRIVACY / FRAMEORDER

Privacy, in plain words.

FrameOrder copies, organizes, and verifies photos and videos you select. It requires no account and includes no advertising, usage analytics, or cross-app tracking. The app does not proactively upload your files, file names, folder paths, or usage records to the developer.

Last updated: October 25, 2026 · Applies to FrameOrder for iOS and this support website.

File access

You grant access to source and destination folders through the system file picker. The app reads file contents, names, sizes, and modification dates to browse, organize, identify duplicates, copy, and verify files. It writes files to the destination you select. Disk capacity is used to display available space and check space for writes. Timing information is used to display import speed and elapsed time.

Information stored locally

The app stores settings, access bookmarks for selected folders, and a verification cache in its app storage. The cache may contain file paths, sizes, modification dates, and checksums. System services may generate and cache thumbnails. This information helps restore folder access and makes browsing and duplicate checks more efficient.

Permissions and system services

The system may request permissions related to external memory cards or image capture devices so that FrameOrder can recognize them. FrameOrder does not use the camera to take pictures. Background tasks may show import status on the Lock Screen or Dynamic Island. iCloud or other file providers you select may download or sync files according to their own settings. System backups are controlled by your device settings. Those services have their own privacy policies.

Managing and deleting data

You can stop an import and manage your files using the system Files app. Deleting FrameOrder, rather than offloading it while retaining data, removes its local app data. Manage system backups, third-party file services, and external storage separately. Deleting the app does not automatically delete files copied to external drives or other providers.

Support requests

If you email us, the developer receives the email address and information you choose to send. This information is used to respond to and resolve your request. Support correspondence is retained for handling and following up on the request. To request deletion of your support correspondence, contact the same address. Please do not send private photos, videos, or unrelated personal information. Email is handled by the email service providers involved.

This website

This website contains no analytics scripts, advertising, tracking cookies, or remote fonts. When hosted on GitHub Pages, GitHub logs visitors’ IP addresses for security purposes. Visiting this website is separate from processing files inside the app. See the GitHub Privacy Statement.

Updates

If future features introduce data collection or otherwise affect privacy, the privacy information and App Store disclosures will be updated accordingly.
