BEFORE YOU IMPORT

Keep a backup. Keep your peace of mind.

Keep an independent backup of important files. Before deleting originals or formatting a memory card, confirm that copying and verification succeeded, open files at the destination to check them, and make sure another backup is available. Verification helps check file integrity; it does not replace a backup.

Your first import

Copy first, then verify.

01

Choose the source

Tap Add under Source and select a folder with photos or videos in the system file picker. For external storage, connect it to your iPhone first and confirm it appears in Files.

02

Choose the destination

Select a different destination folder. Review the scanned files and file types. In Settings, optionally enable grouping by device.

03

Import and verify

Tap Start Import. FrameOrder copies the batch first, then verifies the files. Review copied, skipped, and failed counts on the result screen.

Before testing, start with a small set of files and keep your original files. The app shows the outcome of each import on the result screen.

Frequently asked questions

Do I need an account or an internet connection?

No account is needed. Copying and verification of locally available files work offline. iCloud and other file providers may need internet access to make files available.

Can I try it without an external drive?

Yes. In Files, create Source and Destination folders under On My iPhone → FrameOrder. Copy sample photos or videos into Source, then select those folders in the app. Keep the two folders separate.

Why can’t I see my drive or card reader?

Check whether it appears in the system Files app. If it does not, check the cable, adapter, power supply, and file system compatibility. If it appears there but is unavailable in FrameOrder, try selecting the folder again.

Can I lock the phone during an import?

Follow the status message shown during the import. Background imports and Lock Screen / Dynamic Island progress depend on your iOS version and system scheduling. If the app asks you to keep it open, keep it in the foreground until the import finishes.

Why do some files get skipped?

Files that meet the existing-file comparison criteria may be skipped. Skipped files are reported separately and are not included in the amount of data being copied or verified. Review the result screen after each import.

What should I do if an import stops or a drive disconnects?

Reconnect the drive, confirm that both folders are accessible, and start another import. Review the final result and any failures. Do not assume an interrupted import completed or will automatically resume.

Why might the system ask for camera-related permission?

FrameOrder uses image capture device support to recognize connected memory cards and devices. It does not take photos or videos. You can still choose folders manually through the system file picker.

How do I delete app data?

You can manage files in the system Files app. Deleting FrameOrder removes its local app data; offloading the app retains data. Save anything you want to keep from the app’s Documents folder first. Copies on external drives, cloud providers, and backups are managed separately.
