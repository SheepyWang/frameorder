把隐私说明白。

影序用于复制、整理和校验你选择的照片与视频。应用无需注册账号，不包含广告、用户行为分析或跨应用跟踪功能，也不会主动把文件、文件名、目录路径或使用记录上传给开发者。

文件访问

你通过系统文件选择器授予来源和目标目录的访问权限。应用读取文件内容、名称、大小和修改时间，用于浏览、整理、重复文件识别、复制和完整性校验，并将文件写入你选择的目标。磁盘容量仅用于显示可用空间及检查写入空间；计时信息用于显示导入速度和耗时。

保存在本机的信息

应用在自身存储空间保存设置、已选择目录的访问书签和校验缓存。校验缓存可能包含文件路径、大小、修改时间和校验值。缩略图可能由系统服务生成和缓存。这些信息用于恢复目录访问及提高浏览、重复文件检查的效率。

权限与系统服务

系统可能为识别外接存储卡或图像采集设备请求相关权限，影序不使用摄像头拍摄。后台任务可在锁屏或灵动岛显示导入状态。你选择的 iCloud 或其他文件提供服务可能根据自身设置下载或同步文件；系统备份也由设备设置控制，这些服务适用各自的隐私规则。

管理与删除

你可以停止导入，并在系统“文件”应用中管理自己的文件。删除影序应用（而非仅卸载以保留数据）会移除其本地应用数据；系统备份、第三方文件服务和外部存储中的文件需分别管理。删除应用不会自动删除已复制到外接硬盘或其他提供服务中的文件。

支持邮件

如果你发送支持邮件，开发者会收到你的邮箱地址及你主动提供的信息。这些信息用于回复、处理和跟进你的请求，相关邮件会为此保留。如需删除支持邮件中的信息，请通过同一邮箱联系。请勿发送私人照片、视频或无关个人信息。邮件由相关电子邮件服务提供商处理。

关于本网站

本网站未加入统计脚本、广告、追踪 Cookie 或远程字体。通过 GitHub Pages 托管时，GitHub 会出于安全目的记录访问者的 IP 地址。访问本网站与应用内处理文件是不同的场景。详情请查看 GitHub 隐私声明。

政策更新

如未来增加数据收集或其他影响隐私的功能，将同步更新隐私说明及商店隐私信息。
